GitHub archief⌂

Wat doet dit

Zet een kopie van je GitHub-repo's in OneDrive, in Scripts/GitHub archief/<naam repo>, met dezelfde mappen en bestanden als op GitHub. Klik je later opnieuw, dan worden alleen gewijzigde en nieuwe bestanden bijgewerkt. Bestanden die op GitHub zijn verwijderd blijven in het archief staan.
